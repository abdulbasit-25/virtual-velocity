VIRTUAL VELOCITY WEBSITE - SECTIONS & PAGES DOCUMENTATION
===========================================================

OVERVIEW
--------
Virtual Velocity is a full-service digital marketing & growth agency website built with Next.js 15, React 19, and TypeScript. The site features advanced animations using GSAP, Framer Motion, and custom WebGL effects.

TECH STACK
----------
- Framework: Next.js 15 (App Router)
- Language: TypeScript
- Styling: Tailwind CSS v4
- Animations: GSAP, Framer Motion
- 3D/WebGL: Three.js, OGL
- Icons: Lucide React
- Fonts: Outfit (display), Calibri (body)

===========================================================
PAGES & ROUTES
===========================================================

1. HOME PAGE (/)
---------------
Main landing page - Single Page Application with multiple sections
File: src/app/page.tsx

Navigation Links (from Navigation.tsx):
- ABOUT  → /about
- BLOG   → /blog
- CONTACT → /contact
- CTA Button: "LET'S TALK" → /contact

2. ABOUT PAGE (/about)
----------------------
Studio manifesto, leadership team, and global operational hubs
File: src/app/about/page.tsx (server) + src/app/about/AboutClient.tsx (client)

3. BLOG / JOURNAL (/blog)
--------------------------
Digital journal & thought leadership articles
File: src/app/blog/page.tsx (server) + src/app/blog/BlogClient.tsx (client)

Individual Blog Posts: /blog/[slug]
File: src/app/blog/[slug]/page.tsx
Static generation via generateStaticParams from BLOG_POSTS data

4. CAREERS PAGE (/careers)
---------------------------
Hiring openings for Next.js developers, SEO specialists, UI/UX designers, WebGL engineers
File: src/app/careers/page.tsx (server) + src/app/careers/CareersClient.tsx (client)

5. CONTACT PAGE (/contact)
--------------------------
Project estimator & consultation booking
File: src/app/contact/page.tsx (server) + src/app/contact/ContactClient.tsx (client)

6. LEGAL PAGES
--------------
- /privacy-policy - Privacy Policy & Data Protection Framework
- /terms-of-use   - Terms of Use & Legal Framework

===========================================================
HOME PAGE SECTIONS (In Order)
===========================================================

The home page is composed of these sections (src/app/page.tsx):

1. CUSTOM CURSOR & SOUND TOGGLE
   - Components: CustomCursor, SoundToggle
   - Global interactive cursor with particle trails
   - Ambient web audio toggle

2. NAVIGATION HEADER
   - Component: Navigation (src/components/layout/Navigation.tsx)
   - Fixed header with logo, nav links, mobile drawer
   - Magnetic hover effects on links and CTA

3. GSAP HERO TIMELINE (Section 1)
   - Component: GSAPHeroTimeline (src/components/sections/GSAPHeroTimeline.tsx)
   - GSAP timeline-powered hero entrance animation
   - 3D canvas background with particle systems

4. ABOUT VIRTUAL VELOCITY (Section 2)
   - Component: About (src/components/sections/About.tsx)
   - Agency introduction and value proposition

5. GSAP REVOLVING SERVICES (Section 3)
   - Component: GSAPRevolvingServices (src/components/sections/GSAPRevolvingServices.tsx)
   - 3D revolving services spectrum showcase

6. WHO WE ARE - CREATIVE HOUSE MANIFESTO (Section 3.5)
   - Component: WhoWeAre (src/components/sections/WhoWeAre.tsx)
   - Creative manifesto and brand philosophy

7. CASE STUDIES WALKTHROUGH (Section 4)
   - Component: GSAPScrollGallery (src/components/sections/GSAPScrollGallery.tsx)
   - Horizontal scroll gallery of selected work/projects

8. PROVEN IMPACT & METRICS (Section 5)
   - Component: LightStatsSection (src/components/sections/LightStatsSection.tsx)
   - Key performance statistics and metrics

9. CLIENTS & PARTNERS (Section 6)
   - Component: ClientPartners (src/components/sections/ClientPartners.tsx)
   - Central anchor with surrounding hexagon client logos

10. CLIENT TESTIMONIALS (Section 7)
    - Component: EditorialTestimonials (src/components/sections/EditorialTestimonials.tsx)
    - Editorial-style client testimonials carousel

11. INTERACTIVE ROI ESTIMATOR CTA BANNER (Section 8)
    - Component: InteractiveCTABanner (src/components/sections/InteractiveCTABanner.tsx)
    - High-impact interactive ROI calculator/estimator

12. PROJECT ESTIMATOR & CONTACT FORM (Section 10)
    - Component: Contact (src/components/sections/Contact.tsx)
    - Contact form and project inquiry

13. GLOBAL STUDIO FOOTER
    - Component: Footer (src/components/layout/Footer.tsx)
    - Comprehensive footer with:
      * Email capture & CTA
      * Navigation links (About, Services, Work, Blog, Careers, Contact)
      * Services highlights (Google Ads PPC, Technical SEO, Paid Social, CRO)
      * Office locations (Wilmington US, Lahore PK)
      * Social links (Behance, LinkedIn, Instagram, X/Twitter)
      * Legal links (Privacy Policy, Terms of Use)

GLOBAL FEATURES
===========================================================

1. Smooth Scrolling - Lenis via SmoothScrollProvider
2. Custom Cursor - Magnetic, particle trail effects
3. Sound Toggle - Web Audio API ambient sounds
4. GSAP Animations - ScrollTrigger, timelines, 3D transforms
5. Framer Motion - Page transitions, hover effects
6. Magnetic Interactions - Cursor-following elements
6. Responsive Design - Mobile-first, breakpoints: sm, md, lg, xl
7. Dark/Light Theme - Currently light theme only (bg-white)
8. Accessibility - Semantic HTML, ARIA labels, focus states
